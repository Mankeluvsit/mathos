# Actual controlled test-field captures

Actual Chromium production-build captures, not the concept image. The native workflow starts a prepared feeding test, verifies its16/32-step reports, then prepares an empty field and authors a grazer, rotation and food with one undo. Screenshots show that real field at step1; capture-state.json identifies the exact initial config, accepted edits and source. Clipboard denial is intentionally exercised to show the selectable fallback. No fake organism or invented analytics is rendered.

Desktop shows the three-column layout with JSON visible; it is hidden by default and can be toggled. Phone Field/Controls/Results captures are390×844; both native browsers also verify320×568, strict page width, full map above playback and reachable44px buttons. This is not a physical-device/Safari certification.

Reproduce after npm run build with node scripts/browser-testfield.mjs. Public review uses --public and ignored captures under .artifacts/testfield-public. Scientific state and every copied/downloaded report are verified with the Node replay tool.
