# Actual presentation-v1 captures

The automatic shared-world browser workflow captures World-only on desktop and phone. These are real Canvas/HTML states, not generated design images. capture-state.json identifies the compiled source, engine, tick and report hash; a precommit build is marked dirty. Desktop uses the neutral profile at step1. The phone view comes later from the controlled edited scenario described in docs/previews/world/capture-state.json; it demonstrates tool access, not an unbiased evaluation.

- [Desktop World-only](world-only-desktop.png)
- [Phone World-only](world-only-phone.png)

The dashboard remains the default; both modes use the same session. Published-build captures are verification artifacts, while committed captures retain their honest local capture provenance.
