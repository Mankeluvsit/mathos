Implemented: strict frozen configuration/schema/example; dimension-aware isolated lifecycle; prepared feeding/growth/inheritance/empty scenarios; resource-accounted author edits and bounded undo; exact replay with same-tick and endpoint edits; actual-step test completion; optional synchronized JSON and files/browser storage; desktop/phone workspace, analytics and copy/download reports.

Full-state SHA256 canonicalizes keys recursively: an initial test exposed different property insertion order in snapshots versus live controller records; the fix changed fingerprint encoding, not physics or outcomes.

Native Chromium/Firefox workflow checks prepare and complete a real test, match downloaded scientific state/metrics in Node, switch learning off live and retain prior updates, author an empty field with actual bodies/food/rotation/undo, reject invalid imports, preserve drafts across Show/Hide JSON, preserve the separate living-world run, and keep playback reachable on390×844 and320×568. No model coefficient or replay fixture was changed to hide it.

Chromium exercises real browser clipboard permission plus forced-denial fallback; Firefox uses a simulated clipboard adapter plus denial fallback because native permission support differs. Every copied/downloaded/selected fallback report replays through the actual Node verifier. This is not physical-device/OS-clipboard/Safari or full screen-reader certification. Zero external runtime requests are asserted. Actual captures are in previews/testfield; the earlier concept remains labeled a proposal.

Limits: authored presets illustrate behavior, not held-out evaluation or guaranteed mutation/adaptation. Rules are bounded; no arbitrary code/controller/genome editor. Every edit is explicit external input/output; the field does not masquerade as a closed untouched ecology. No installed offline cache, resumable checkpoint or external analytics service. Reports are replay recipes plus observed metrics; the owner chooses to share them.
