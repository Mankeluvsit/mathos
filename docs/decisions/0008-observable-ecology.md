# ADR 0008 — recognizable organisms before broader simulation depth

Status: implementation decision responding to owner review of the integrated baseline.

Preserve substrate-reference@1 and life-reference@1 unchanged. Add ecology-reference@1, an integer grid model with bounded spatial foragers, as a separate first-experience laboratory. Definition format mathos-ecology@1: seed uint32, mode seeded|primordial. Fixed world 64×48, max 48 living organisms, 256 lifetime births, 1600 ticks. No arbitrary imported rules. Small format uses its own local slot; export is restart-only.

Initialization consumes mulberry32 draws for 360 food placement attempts (each successful placement adds 24 units), then places up to eight authored three-cell foragers in separated deterministic slots, with 120 stored +24 structural units each. Both are declared initial resources. Primordial adds no organisms. Each tick attempts three seeded food placements (24 units each only on empty food sites without bodies), recording those units as external sunlight input.

Tick order: sunlight food → increasing-ID organism lifecycle → observation. Body cells are contiguous horizontal sites from anchor x through x+size-1, independent of travel direction. Cell 0 stores/controller, cell 1 mouth, remaining cells motors. Closed world boundaries. Mouth harvests up to 24 units on its own or four neighboring sites. Only the mouth performs intake. Metabolism costs one unit per tick; a move costs 2 units and needs a motor. Energy depletion or age>=genome.lifespan causes death; remaining stores/structure explicitly dissipate. No corpse/predation model yet.

Each organism senses visible food within Manhattan radius genome.sense around its anchor, reduced into north/east/south/west signals sum(floor(food/ distance)). Four integer neural scores = genome.foodWeight × directionalSignal + genome.inertia × indicator(previousDirection). Greedy maximum chooses direction, first max in N/E/S/W. If no signal, one seeded draw chooses a direction. Attempt the chosen move then remaining directions cyclically, rejecting walls/body overlap. The first allowed action is performed; failure is reported as blocked. No global pathfinding or teleported food access. Controller weights are inherited genes, not learned lifetime weights.

At energy>=80 and age>=10, a two-cell juvenile can add one motor cell for 8 units if the site is empty. Initial founders are mature three-cell bodies. At age>=40, >=80 ticks since last birth and energy>=260, search the parent's surrounding +/-8 square in stable y/x order for a nonoverlapping two-cell child anchor at Manhattan distance>=5. Child receives 100 stored +16 structural units deducted from parent. Newborns act next tick. One draw mutates with probability 1/4; another chooses sense/foodWeight/inertia/lifespan and +/-1 (lifespan step 40), clamped to sense 3–8, weight 1–6, inertia 0–6, lifespan 240–1000. Record whether a gene actually changes. Initial genes: sense6, foodWeight3, inertia2, lifespan600.

Exact ledger: initial + sunlight = food + organism stores +8×body cells + cumulative dissipated. Stable-ID conflict priority is explicit. Retain at most256 lineage records and40 recent lifecycle events. Versioned RNG state is part of engine state; each transition copies predecessor-owned arrays/records. Renderer/selection/zoom/rate do not participate. Age and cooldown stop geometric overgrowth; movement and functional body marks make entities observable. These choices are a toy ecological reference, not a validated biological model or an implementation of the references' complete systems.
